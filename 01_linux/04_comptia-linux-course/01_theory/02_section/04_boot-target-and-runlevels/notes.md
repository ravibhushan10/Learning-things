common Runlevels:

0  : Halt the system
1  : single user mode
2  : multi user mode without file system
3  : full multi user mode without GUI 
4  : unused
5  : full multi user mode with GUI 
6  : reboot the system

You can go to each runlevel by "telinit" command
telinit 1  : go to first level
telinit 2  : go to second level
