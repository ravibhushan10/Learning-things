Iterable: iterable object is a something that contains the countable number of elements. and we iterate through one by one from start to end.

<!-- ******* -->
Any iterable has at least two method:
__iter__()
__next__()

<!-- ********* -->
All iterable list
range
list
dict
tuple
set
str
bytes
bytearray
frozenset
