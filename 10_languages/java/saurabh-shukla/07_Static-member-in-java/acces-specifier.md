<!-- **** class access specifier**** -->
2 access specifiers for a top-level class:

-> public – the class is accessible from anywhere.
-> default (no keyword) – the class is accessible only within the same package (also called        package-private).


Note: private and protected are not allowed for top-level classes. However, for inner (nested) classes, all 4 access specifiers can be used: public, protected, default, and private.

<!-- **** member  variable access specifier**** -->
public – accessible from anywhere.
private – accessible only within the same class.
protected – accessible within the same package and subclasses.
default (no keyword) – accessible only within the same package (package-private).
