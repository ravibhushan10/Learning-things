Java is  100% object oriented language. But what about primitive data types.

-> 100% object oriented means anything stores a data must be an object.
but , int x=23, y=34;  this is not an object.


<!-- *********** -->
So achieve the 100% oops we use the "wrapper class".

-> For every primitive data types already built in class present, that contain only one data type corresponding to it.
-> this class encapsulate a single value for the primitive data type.

<!-- *********** -->
PRIMITIVE TYPE  ->   WRAPPER CLASS

boolean -> Boolean
char    -> Character (exception in spelling)
short   -> Short
int     -> Integer (exception in spelling)
float   -> Float

.... for the "double, byte, long..
