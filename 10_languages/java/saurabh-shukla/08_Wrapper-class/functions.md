<!-- **** valueOf() ***** -->
-> it is a static method (no need of object to call it)
-> return object reference of relative wrapper class.


<!-- **** parseXxx() ***** -->
-> it is a static method (no need of object to call it)
-> Xxx can be replace with any primitive type(int,char,short,float ....).
-> it return Xxx type value.

<!-- **** XxxValue() ***** -->
-> instance method of wrapper class not an static method ( you need an object to call this function).

-> Xxx can be replace with any primitive type
-> returns corresponding primitive type.
