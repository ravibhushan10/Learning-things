Talking about the member variable accessibility(variable, method, constructor)

private  <  default  <  protected  <  public
(least visible)              (most visible)


private member:  This is accessible only from the inside of that class, not even the same package.

default member: access only within the same package.

protected member: access by the derived class, and also accessible by the same package with the all classes.

public member: it is accessible from the any where from the any package and the class.
