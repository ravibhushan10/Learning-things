Constructor : A constructor is a special block of code that runs automatically when an object is created using the new keyword. Its job is to initialize the object's state (set values to fields).


-> It is a special member function of a class which has the same name(exact case-sensitive) as class name.
-> Constructor has no return type. even void' you can't write otherwise java treat as a normal function.

Why constructors exist (the WHY): Without one, every object would be created with default/garbage-looking values (null, 0, false), and you'd have to manually call setter methods every single time before using the object.
